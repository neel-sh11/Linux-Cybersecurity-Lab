Linux Cybersecurity Lab

A hands-on repository documenting my learning journey through Linux fundamentals and cybersecurity concepts.

Objectives

* Learn essential Linux commands and the command-line environment.
* Understand the Linux file system and navigation.
* Practice file permissions and ownership.
* Learn about users and groups.
* Explore processes and basic system management.
* Understand networking fundamentals.
* Analyze Linux logs and security-related information.

Topics Covered

01. Linux Navigation and File System

* Navigating directories
* Understanding the Linux file system
* Creating files and directories
* Listing files and directories
* Viewing file contents
* Using absolute and relative paths

02. File Permissions and Ownership

* Understanding Linux permissions
* Read, write and execute permissions
* Using chmod
* Understanding file ownership
* Using chown
* Security relevance of permissions

03. Users and Groups

* Understanding Linux users
* Understanding groups
* Checking user information
* File ownership and users
* Basic access control concepts

04. Process Management

* Understanding processes
* Viewing running processes
* Process IDs (PID)
* Managing processes
* Basic system monitoring

05. Networking Fundamentals

* Understanding IP addresses
* Checking network configuration
* Testing connectivity
* Basic networking commands
* Network-related security concepts

06. Log Analysis

* Understanding system logs
* Reading log files
* Identifying important events
* Failed login attempts
* Basic security monitoring

Learning Approach

Each topic will include:

* Key concepts
* Linux commands
* Practical examples
* Command outputs
* Security relevance
* Notes and lessons learned

Environment

* Linux terminal environment
* Command-line tools
* iPhone-based learning setup

Progress
